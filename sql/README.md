# SQL — Scripts du projet

Organisation chronologique :

- `00_setup/`       : création de la base et des schémas
- `01_import/`      : création des tables raw + import des CSV
- `02_staging/`     : nettoyage et standardisation (Phase 6)
- `03_core/`        : modèle relationnel cible (Phase 9)
- `04_analytics/`   : KPI et analyses métier (Phases 16-22)
- `05_advanced/`    : views, functions, triggers (Phases 23-27)
- `06_performance/` : indexes, EXPLAIN, optimisation (Phases 28-31)
- `07_tests/`       : tests de qualité (Phase 32)
