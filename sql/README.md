# SQL Scripts

Chronological organization:

- `00_setup/`       : database and schema creation
- `01_import/`      : raw tables creation + CSV import
- `02_staging/`     : cleaning and standardization (Phase 6)
- `03_core/`        : target relational model (Phase 9)
- `04_analytics/`   : KPIs and business analyses (Phases 16-22)
- `05_advanced/`    : views, functions, triggers (Phases 23-27)
- `06_performance/` : indexes, EXPLAIN, optimization (Phases 28-31)
- `07_tests/`       : data quality tests (Phase 32)
